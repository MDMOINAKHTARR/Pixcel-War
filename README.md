# 🏎️ Pixel-War: Battle Arena & Arcade Kart Racer

> **A fast-paced, top-down arcade kart combat & racing game built with React, TypeScript, and HTML5 Canvas. Battle opponents with homing missiles, lasers, mines, and vulcan cannons, or power-drift through 6 dynamic circuits to claim victory on the Monad Testnet!**

---

## 📌 Short Description
**Pixel-War is a high-octane top-down arcade kart combat & circuit racer featuring 12 unique vehicles, an arsenal of dynamic battle weapons, 6 diverse tracks, and Web3 tournament rewards on the Monad Testnet.**

---

## 🌟 Key Features

- ⚔️ **Dual Game Modes**:
  - **Battle Royale / Arena Combat**: Hunt mystery weapon crates, build killstreaks, and survive as the last kart standing.
  - **Circuit Grand Prix**: 3-lap competitive racing with 3-tier drift boosts, turbo boost pads, and apex timing.
- 🚀 **12 Distinct Vehicles**:
  - *Quantum Rocket Jet*, *Red Lightning GT*, *Police Interceptor*, *Surf Woody Wagon*, *Heavy 4x4 Pickup*, *British Roadster*, *Santa Sleigh Cruiser*, *Agro Harvester*, *Bigfoot Monster Truck*, *Grand Prix Cigar F1*, *Dark-M Stealth*, and *Classified Prototype*.
  - Persistent battle damage feedback (paint scuffs, armor dents, smoking engine vents, and electrical sparks).
- 💥 **Arsenal of Battle Weapons**:
  - ⚡ *Twin Blaster* • 🔥 *Gatling Vulcan* • ⚡ *Railgun Laser* • 💣 *Proximity Landmines* • ❄️ *Homing Cruise Missiles* • ⚡ *EMP Shockwaves* • 🚀 *Rocket Boost Rush* • 🛡️ *Plasma Energy Shields*.
  - Lock-on crosshair targeting reticle and position-weighted rubber-banding distribution.
- 🗺️ **6 Diverse Tracks & Arenas**:
  - **Blocky Town Grand Plaza**: Dense modern city district with park fountain, cafe patio, and parking lot.
  - **Desert Canyon Raceway**: Arid sandstone cliffs with sweeping high-speed straights.
  - **Snowy Peak Circuit**: Sub-zero alpine speed ring with frosted pine trees and ice shores.
  - **Industrial Apex Matrix**: High-velocity steel corridors and chemical refinery chicanes.
  - **Volcanic Canyon Arena**: Black obsidian canyon with glowing magma shoreline rivers.
  - **Monad Quantum Nexus**: 10,000 TPS orbital battle platform with void hazards and quantum boost rings.
- 📊 **Retro Pixel HUD & Radar**:
  - Live Digital Speedometer, HP/Shield gauges, active weapon ammo slot, live combat killfeed, and circular radar minimap.
- 🔊 **Zero-Asset Procedural Web Audio Engine**:
  - Synthesized engine frequencies, drift screech tones, missile launches, laser pulses, and victory fanfare.
- ⛓️ **Monad Testnet Web3 Integration**:
  - Claim on-chain `$SMASH` token prizes and mint Driver License NFTs on Monad Testnet (`Chain ID: 10143`).

## 🎮 Controls

| Action | Keyboard Controls |
| :--- | :--- |
| **Accelerate / Reverse** | `W` / `S` or `Up` / `Down Arrow` |
| **Steer Left / Right** | `A` / `D` or `Left` / `Right Arrow` |
| **Fire Weapon** | `Space` / `F` / `E` / `Enter` |
| **Power Drift** | `Shift` / `C` |
| **Pause Match** | `ESC` / Top-left chrome button |

---

## 🛠️ Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Rendering Engine**: HTML5 Canvas 2D with custom vector geometry & procedural shaders
- **Audio Engine**: Web Audio API (100% procedural synthetic sound)
- **Web3**: ethers.js v6 + Monad Testnet

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/MDMOINAKHTARR/Pixcel-War.git

# Navigate to project directory
cd Pixcel-War

# Install dependencies
npm install

# Start development server
npm run dev
```

Open **[http://localhost:3000/](http://localhost:3000/)** in your browser to play!
