# 🏎️ Pixel-War: Retro Pixel Arcade Kart Racer

> High-speed browser-based multiplayer & single-player arcade kart racer inspired by *Pixel Wheels* and *SmashKarts*, featuring 12 procedural pixel-art vehicles, 5 dynamic circuits (including the brand-new *Volcanic Canyon*), 3-tier drift boost mechanics, synthetic Web Audio, and Web3 integration on Monad Testnet!

---

## 🌟 Key Features

- 🚗 **12 Procedural Pixel-Art Vehicles**:
  - *Red Lightning*, *Police Interceptor* (with animated siren lightbar), *Surf Woody Wagon*, *Classic Tan Pickup*, *Green Roadster*, *Santa Sleigh Truck*, *Agro Harvester*, *Camo Bigfoot*, *Retro GP Racer*, *Dark-M Stealth*, *Quantum Rocket*, and *Classified Mystery Vehicles*.
- 🏁 **5 Diverse Racing Circuits**:
  - **Blocky Town Circuit**: Classic urban street raceway with terracotta roofs and tight chicanes.
  - **Desert Canyon Raceway**: Arid sandstone curves with sweeping sand straights.
  - **Snowy Peak Circuit**: Sub-zero snow mountain track with icy water ripples and frosted pine trees.
  - **Industrial Apex Matrix**: High-velocity steel corridors and long straightaways.
  - **Volcanic Canyon** (*New!*): Black obsidian canyon with glowing magma shoreline rivers and caldera hairpin.
- ⚡ **Pure Skill-Based Racing Mechanics**:
  - **3-Tier Drift Spark Boost System**: Blue (+35%), Orange (+60%), and Purple Supreme (+100%).
  - **Track-Side Turbo Boost Strips**: Speed pads at natural acceleration straightaways.
  - **Checkered Start/Finish Line**: Starting grid boxes with asphalt countdown timer.
  - **Realistic Elastic Collisions**: Dynamic kart-to-kart bumping and wall physics.
- 📊 **Retro Pixel In-Race HUD**:
  - Live Digital Speedometer (`KM/H`) & 3-Tier Drift Gauge.
  - Plate-backed Rank Badge (🥇 1st Gold, 🥈 2nd Silver, 🥉 3rd Bronze).
  - Unified Lap Counter (`🏁 LAP 1/3`, `🏁 FINAL LAP`).
  - Lap Time & Best Lap Record tracking.
  - Circular Radar Minimap showing track outline and racer positions.
- 🔊 **Zero-Asset Synthetic Web Audio**:
  - Fully procedural synthesized engine pitch, tire screech drift audio, turbo boost whoosh, countdown tones, and race horn.
- ⛓️ **Monad Testnet Web3 Integration**:
  - Chain ID: `10143` | RPC: `https://testnet-rpc.monad.xyz` | Native Currency: `MON`.
  - On-Chain ERC-20 `$SMASH` Token prizes & ERC-721 Pilot License NFTs.

## 🎮 Controls

| Action | Controls |
| :--- | :--- |
| **Accelerate** | `W` / `Up Arrow` |
| **Brake / Reverse** | `S` / `Down Arrow` |
| **Steer Left / Right** | `A` / `D` or `Left` / `Right Arrow` |
| **Power Drift** | `Shift` / `Space` / `C` |
| **Pause Race** | `ESC` / Top-left chrome button |

## 🛠️ Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Retro Pixel Design System (`Press Start 2P`, `Silkscreen`, `Rajdhani`)
- **Rendering Engine**: HTML5 Canvas 2D with custom pixel-art vector geometry
- **Audio Engine**: Web Audio API (100% synthetic procedural sound)
- **Web3**: ethers.js v6 with Monad Testnet wallet provider

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/MDMOINAKHTARR/Pixcel-War.git
cd Pixcel-War
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser!

### 4. Build for production
```bash
npm run build
```
